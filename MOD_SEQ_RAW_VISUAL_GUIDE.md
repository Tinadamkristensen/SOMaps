## Key Differences

| Feature | mod_raw | mod_seq_raw |
|---------|---------|-------------|
| **Origin** | Observed data from dataset | Generated by linspace |
| **Count** | n observations (e.g., 50) | Always 100 points |
| **Spacing** | Irregular (as measured) | Perfectly even |
| **Range** | [min, max] of observations | [min, max] same range |
| **Purpose** | Actual data values | Smooth plotting grid |

## Why Use Both?

1. **mod_seq_raw** creates a smooth, continuous line showing the predicted relationship
2. **mod_raw** shows where your actual data points are located
3. Together they show: "Here's what the model predicts (smooth line) and here's what we actually observed (dots)"

## Analogy

Think of it like:
- **mod_raw**: Taking photos at random locations along a road
- **mod_seq_raw**: Drawing a smooth line at regular intervals along the same road

The smooth line helps visualize the overall trend, while the photos show the actual observations.

## Code Summary

```matlab
% What you have (irregular data)
mod_raw = [1.2, 3.5, 2.1, 8.9, 5.3, ...]

% What you create (smooth sequence)
mod_seq_raw = linspace(min(mod_raw), max(mod_raw), 100)'

% Result:
% mod_raw     = 5 points (irregular)
% mod_seq_raw = 100 points (evenly spaced from 1.2 to 8.9)
```

This allows you to:
1. Plot a **smooth prediction line** across the entire range
2. Overlay **actual data points** to see real observations
3. Show both the model's predicted relationship AND the actual data together
