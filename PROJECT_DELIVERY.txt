FEATURE 1: CONFIDENCE INTERVALS FOR β
--------------------------------------
Implementation: Lines 217-229 in PUFA_WM_permute.m
Method: Covariance-based confidence intervals
Statistics: Uses full coefficient covariance matrix with t-distribution
Output: Beta coefficients with [lower, upper] 95% CI bounds
Benefit: Proper uncertainty quantification for all estimates

Example Output:
  FA_corpus_callosum  beta = 0.01234 [0.00456, 0.02012]

FEATURE 2: STANDARDIZED EFFECT SIZES
-------------------------------------
Implementation: Lines 231-235 in PUFA_WM_permute.m
Method: Beta / Residual SD (Cohen's d-like)
Statistics: Uses model RMSE for standardization
Output: Standardized effect for each ROI
Benefit: Scale-free interpretation, comparable across studies

Interpretation:
  |d| < 0.2 : Small effect
  |d| ≈ 0.5 : Medium effect
  |d| ≈ 0.8 : Large effect

Example Output:
  std.effect = 0.234 (small to medium effect)

FEATURE 3: PERMUTATION-BASED GLOBAL TEST
-----------------------------------------
Implementation: Lines 113-174 in PUFA_WM_permute.m
Method: Non-parametric permutation test
Permutations: 1,000 (default, adjustable)
Statistics: Permutes group labels at subject level, refits model
Output: Permutation p-value and null distribution visualization
Benefit: Robust inference without distributional assumptions

Example Output:
  Observed F = 3.456
  Permutation p-value = 0.0034
  (Based on 1000 permutations)
